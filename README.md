# Solitaire

Free Klondike solitaire that runs in your browser — no ads, no account, no tracking.

**Play it here: https://spradlin-dev.github.io/solitaire-app/**

## Why this one?

- **No ads, ever.** Nothing to buy, nothing to watch, no popups.
- **Works offline.** After your first visit, the game loads and plays with no
  internet connection at all.
- **Installable.** Add it to your phone's home screen or your computer and it
  opens like a regular app, full screen.
- **Private.** Your games and stats are saved on your own device and never
  leave it.

## Features

- Draw 1 or Draw 3
- Unlimited undo, hints, and auto-finish
- Hints can prove a deal unwinnable, so you know when to stop
- Timer and move counter, with a pause menu that stops the clock
- Win/loss stats, streaks, best times
- Share any deal as a link so a friend can try the same one

## Installing it

- **iPhone/iPad:** open the game in Safari, tap Share, then "Add to Home Screen".
- **Android:** open it in Chrome and tap "Install" (or Menu → "Add to Home screen").
- **Computer:** in Chrome or Edge, click the install icon at the right end of the
  address bar.

Installing is optional — the site works the same in a normal browser tab.

## Development

Vite + React + TypeScript + pixi.js. `npm ci`, then `npm run dev`. Tests with
`npm test`. The full design doc lives in [docs/DESIGN.md](docs/DESIGN.md).
